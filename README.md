## 📢 小狗浏览器 / 家客现场维护综合助手 v1.0.1

本次更新为**关键通信与安全协议升级版本**，全面重构了固件调度与现场测速模块。

### 🛠️ 更新日志
* **核心修复**：修复零配置扫码偶发性崩溃闪退，优化长 Ping 探测与后台长连接会话机制。
* **融合测速**：集成离线拟合测速算法，动态联动信号衰减（适配 5G 频段），支持现场一键生成并导出 PNG 测试报告。
* **设备解锁**：深度适配 RAX3000Ze（三码读写/地区码修改/Telnet激活）、RAX3000Z（快照读取与一键执行）以及 TC7102 多步顺序刷机。
* **安全调度**：固件移至云端按需静默下载，刷机完成后采用底层物理覆写粉碎（阅后即焚），不占用设备存储，APP 安装包大幅缩减至 10MB 左右。
